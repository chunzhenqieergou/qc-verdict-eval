# 答案顺序的推理对照

本轮固定全部权重，只换作答指令。原顺序为结论、数值、理由，对照顺序为数值、结论、理由。理由位置固定。使用同一批 144 题、原有七个模型条件、相同批次和解码预算。该实验用于决定是否值得重新训练不同答案顺序的适配器。

统一评测找出单独成行且唯一无歧义的“成立”或“不成立”，两个条件均适用。另报是否实际在数字后给结论、旧顺序和新顺序的成对判断率、规则簇配对区间、预测“成立”的频数。以两个训练组三个种子的 120 道新场景结果为主，底座作参照。如果多数适配器依然沿用旧顺序，结论限于换提示的干预；匹配训练格式的复现列入下一阶段。当前检验属于看到原结果后提出的探索性分析。

在查看新顺序的评分之前，增加多场景组三种子的训练对照。由同一底座重新训练，将训练提示与答案中的前两行一并互换，固定理由在第三行。用原提示、新提示分别测试新权重，与此前旧权重的两个提示构成四格对照。主要差值为两种匹配条件的成对正确率差（原训原测与新训新测）。三个种子配对，规则簇区间用于描述本题库。如果成对得分仍低于 15% 或区间跨零，该设计不支持继续把整体判断改善归因于答案顺序。成功复现仍需不同模板和独立数据才能作为论文外推证据。
