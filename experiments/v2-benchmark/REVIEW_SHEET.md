## 1. 12 条规则边界与等号定义（请重点核验等号与两层比较）

| 规则 | 规则族 | 比较算子 | 边界与等号说明 | 参考来源 |
|---|---|---|---|---|
| `single` | sampling | `<=` | 不合格品数 x <= 接收数 c 时判定成立（含等于）；x > c 不成立。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section2/pmc23.htm) |
| `first_accept` | sampling | `<=` | 首样不合格品数 x1 <= 首样接收数 c1 时首样直接接收成立（含等于）；x1 > c1 不成立。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section2/pmc251.htm) |
| `first_reject` | sampling | `>=` | 首样不合格品数 x1 >= 首样拒收数 r1 时首样直接拒收成立（含等于）；x1 < r1 不成立。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section2/pmc251.htm) |
| `second_accept` | sampling | `<=` | 两样本累计不合格品数 x1 + x2 <= 累计接收数 c2 时接收成立（含等于）；x1 + x2 > c2 不成立。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section2/pmc251.htm) |
| `weco3` | control_chart | `>` | 单点标准化偏差 z > 3 时触发越限（严格大于，z = 3.00 不触发）。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc32.htm) |
| `weco2` | control_chart | `>=` | 两层比较：①逐点严格高于 +2.00σ（等于 +2.00 不计入）；②窗口3点中计入点数 >= 2 时触发（含等于）。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc32.htm) |
| `weco1` | control_chart | `>=` | 两层比较：①逐点严格高于 +1.00σ（等于 +1.00 不计入）；②窗口5点中计入点数 >= 4 时触发（含等于）。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc32.htm) |
| `weco8` | control_chart | `>=` | 两层比较：①逐点严格高于 0.00σ（等于 0.00 不计入）；②窗口8点中计入点数 >= 8 时触发（即全8点均严格大于0）。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc32.htm) |
| `cp` | capability | `>=` | Cp = (USL - LSL) / (6 * sigma) >= target 时达标（含等于）；真值按未舍入精确值判定，并剔除舍入歧义题。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc16.htm) |
| `cpu` | capability | `>=` | Cpu = (USL - mean) / (3 * sigma) >= target 时达标（含等于）；真值按未舍入精确值判定。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc16.htm) |
| `cpl` | capability | `>=` | Cpl = (mean - LSL) / (3 * sigma) >= target 时达标（含等于）；真值按未舍入精确值判定。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc16.htm) |
| `cpk` | capability | `>=` | Cpk = min((USL - mean)/(3*sigma), (mean - LSL)/(3*sigma)) >= target 时达标（含等于）；真值按未舍入精确值判定。 | [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc16.htm) |
